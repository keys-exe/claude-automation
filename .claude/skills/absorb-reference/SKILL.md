# Absorb a reference (§42)

Seven parts, in order, none skipped. Output is `absorption_sheet.md` (Build Sheet content,
Appendix C item 3a).

## Part 1 — Measure before read
Measure first, interpret second. Build the metric table: beat count, average beat length,
cut rate, talking-head/B-roll ratio, first-product-appearance timestamp, hook length,
claim count and where each lands.

## Part 2 — Structure map, in the build system's vocabulary
Translate what you measured into our terms: acts, registers, retention beats, framing steps,
energy classes. Not "then there's a montage" — `BR-07..BR-11, doc register, lift, R1`.

## Part 3 — Style Lock
**Set, not proposed.** Copy the winner's style exactly. Secondary references contribute
named devices only, each recorded position-not-look.

## Part 4 — Script absorption
The other half of why it won: reference phrase inventory, copy formula, voice fingerprint,
beat map. This is the one place slot-by-slot rewriting is script *authoring* and is allowed
(it sits at §18 step 2, not inside the build).

## Part 5 — Surfaced, not absorbed
Name what you deliberately did not copy, and why. An unnamed omission reads as an oversight.

## Part 6 — The beat-it plan
What this build does that the reference does not, stated as beats.

## Part 7 — Confirmation gate
State the Style Lock and the beat-it plan back in one block, then continue — §18 keeps
absorption inside the opening delivery. Do not wait here.

## Generated-result measurement
When a generated build is measured against the reference afterwards, the same Part 1 table
is rebuilt from our own output and the two are put side by side.
