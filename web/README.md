# Beat Console — the web front end

**Live: https://claude.ai/artifact/Tg8gix6v7GgWyhozD4gDGP**

The same gates as `pe`, in a browser, for the half of the workflow that is typing and
checking rather than generating. No install, no terminal.

## What it does

- **Script → phrases.** The §27 mechanical split, including the list-of-nouns rule. Triggers
  that are not mechanical come back tagged `REVIEW` rather than guessed.
- **Coverage ledger.** A disposition per phrase, `CUT` refused, `BLOCKED` forced to carry its
  reason and section, and the §27B reconciliation line computed live.
- **Act map.** E4 rows with `story_day` and `capture_event_id` mandatory, and the
  `wardrobe_ref`-without-`story_day` failure caught as you type.
- **Beat editor.** T2I and I2V side by side with the live gates: minified character count
  against the 2,500 ceiling, the §28H word budget, banned punctuation, the sync anchor,
  unfilled slots and leftover bracket instructions.
- **String library.** All 239 Appendix A strings, searchable, insertable, each showing its
  declared count and a `!` where the count has drifted from its block.
- **Export.** Downloads the build as `phrase_inventory.json`, `act_map.json` and
  `beats/{ID}.t2i.txt` / `.i2v.json` — the E9 names, so it drops straight into a build tree.

Checks the browser cannot measure — OCR, pixel ratios, greyscale legibility, a blind voice
listen — are listed as `QUEUED` with their on-fail action, exactly as `pe qa` does. An unwired
instrument never reads as a green check.

## Files

| file | what |
|---|---|
| `console.src.html` | the page source — **edit this one** |
| `strings.json` | generated by `tools/export_strings.py`, never hand-edited |
| `console.html` | build output: source with `strings.json` inlined. Generated |

## Rebuild and republish

```bash
python3 tools/export_strings.py     # after any Standards cut
python3 tools/build_console.py      # injects strings.json into the source
```

Then republish `web/console.html` to the URL above — same URL, new version.

## State

The console stores the current build in the artifact's own database (`builds/main`, with one
document per beat), so it survives reloads and reaches you on another device. Without that
grant it still runs, keeps everything in memory, and says `local only` in the header.
